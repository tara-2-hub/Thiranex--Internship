# Thiranex Internship

## Sales & Revenue Analysis Dashboard

### Objective
Build an interactive dashboard to analyze sales and revenue data, track key performance indicators, identify top-performing products, and generate business insights.

### Tools Used
- Microsoft Excel
- CSV Dataset
- HTML
- JavaScript
- Chart.js

### Key Features
- Total Revenue and Total Profit
- KPI Tracking
- Monthly Revenue Trends
- Revenue by Category
- Revenue by Region
- Top-Performing Products
- Interactive Filters

### Project Deliverables
- Interactive Dashboard
- Excel Workbook
- Sales Dataset
- Project Report
- Dashboard Preview

### Expected Outcome
Develop practical skills in data visualization, KPI tracking, sales performance analysis, and business insight generation.
